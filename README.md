# Gibiflix

Biblioteca e leitor de quadrinhos para Android com leitura guiada quadro a quadro, otimizado para e-ink (Boox Go 7 Color e Boox Go 7) e tablets.

- Importa CBZ, CBR, CB7 e PDF, de arquivos, pastas, outro aparelho ou servidores OPDS (Komga, Kavita).
- Detecta os quadros de cada página e deixa revisar num editor.
- Lê um quadro por vez, passando com os botões de volume.
- Ajusta a imagem para cada tipo de tela e sincroniza o progresso entre aparelhos.
